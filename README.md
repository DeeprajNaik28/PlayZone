# 🎮 Digital Game Store Demo

A simple demo project of a digital game store website built using **HTML, CSS, and JavaScript**.
This project includes basic user account and game listings with a clean and interactive interface.

---

## 🚀 Features

* 👤 Simple User Account
* 🎮 Digital Game Listings
* 🛒 Store-style UI Design
* 🔍 Interactive Product Display
* 📱 Responsive Layout
* ⚡ Fast and lightweight frontend project

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

---

## 📂 Project Purpose

This project was created as a demo of an online digital game store.
It focuses mainly on frontend design, layout structure, and basic interactive features.

---

## 📸 Preview

* Home page with featured games
* Product listing section
* Simple login interface
* Interactive buttons and UI effects

---

## ▶️ How to Run

1. Download or clone the repository
2. Open the project folder
3. Run the `.html` files in your browser
